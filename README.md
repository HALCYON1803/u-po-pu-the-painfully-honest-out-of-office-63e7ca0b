One brutally honest but still polite out-of-office auto-reply, written by
`main.ts` to `/output/entry.txt` (a single sentence, at most 200 characters).

> I'm away until Monday, heroically pretending my 412 unread emails don't exist — thank you for your patience.

The line admits the private truth every employee knows but never types —
that the sender is deliberately ignoring a pile of unread mail — while
staying warm enough that a manager reading it would let it stand.
